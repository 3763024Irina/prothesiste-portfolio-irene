# Portfolio de prothésiste dentaire / Портфолио зубного техника

Site statique bilingue français / russe pour présenter des réalisations en prothèse dentaire, des cas de démonstration et les workflows numériques Exocad DentalCAD, Exoplan et Blender for Dental.

## Mise en ligne
- Activer GitHub Pages dans Settings → Pages, branche `main`, dossier `/(root)`.
- Remplacer les six cartes de démonstration par de vrais cas et photos avant publication professionnelle.
- Renseigner les coordonnées dans `assets/js/config.js`.

## Публикация
- В GitHub откройте Settings → Pages и выберите Deploy from a branch: `main`, папка `/(root)`.
- Шесть карточек в галерее — демонстрационные макеты; замените их своими работами и фотографиями.
- Укажите контакты в `assets/js/config.js`.
